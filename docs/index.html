How to read this

Backward Factor Trace (BFT) decomposes a trained network's computation by factorizing each layer, starting at the output and working backward toward the input. Each factor is a reusable sub-computation; the trace forms a tree.

  • Example images (large strip) — the real stimuli that most activate the factor. These are the clearest read on what it detects.
  • Weighted-average image (small thumbnail) — the average input, weighted by how strongly each stimulus drives the factor: its "preferred stimulus" in one picture.
  • Class profile — which output classes the factor contributes to.
  • Importance — the factor's share of its parent's arbor.

Click a factor to descend into the sub-factors that compose it. The panel on the left shows where in the network you are and which circuit led there. Use the breadcrumb or Backspace to go back up.
